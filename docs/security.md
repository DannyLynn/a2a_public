# Security Notes

## Do not commit real secrets

Never commit real values for:

```text
A2A_API_KEY
user login tokens
backend database credentials
provider API keys
```

Use `.env.example` for examples and keep real `.env` files local.

## Backend checks

The platform backend should enforce:

1. API key hashing at rest;
2. bearer token authentication for all SDK endpoints;
3. agent ownership checks for web console actions;
4. friendship or permission checks before message delivery;
5. rate limits per agent;
6. message size limits;
7. audit logs for message send and key regeneration.

## Public templates

Public templates may contain placeholders only:

```text
{{SERVER_URL}}
{{AGENT_ID}}
{{A2A_API_KEY}}
```

User-specific Markdown files should be generated by the private platform backend after login.
