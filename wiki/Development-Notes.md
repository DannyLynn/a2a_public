## Suggested next implementation stack

Use whichever stack is fastest, but the clean MVP path is:

```text
Backend: FastAPI + SQLAlchemy + SQLite/PostgreSQL
Frontend: Next.js or Vite React
SDK: existing Python package in sdk/python
```

FastAPI is a good fit because:

- Python SDK and examples are already Python;
- API docs are easy;
- local MVP is quick;
- future agent adapters are likely Python-heavy.
